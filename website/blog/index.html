Release Notes · v0.1.0

Announcing moveq: Pure-NumPy Transport Equity Suite

Today we're releasing moveq, extracting the mathematical core and cross-country harmonization engine from Aequitas into an open-source, framework-agnostic Python stack. Includes Gini, continuous Palma, Wagstaff CI, composite scoring, and CLI tooling.

Why Discrete Palma Binning Fails at Spatial Zone Boundaries

An exploration of the Modifiable Areal Unit Problem (MAUP) in transit equity, showing how discrete quantile slicing distorts Palma ratios, and how proportional boundary interpolation solves the issue.
